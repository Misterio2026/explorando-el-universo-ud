# Explorando el Universo con Universal Dynamix

Sitio web educativo, adaptable a computadoras, tabletas y celulares.

## Cómo abrirlo
1. Descomprimí el archivo ZIP.
2. Abrí la carpeta `Explorando_el_Universo_con_Universal_Dynamix`.
3. Hacé doble clic en `index.html` para abrir el sitio en Chrome.

No requiere instalación ni servidor para funcionar.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño visual y adaptación a pantallas.
- `script.js`: menú móvil, año automático y animaciones de aparición.
- `assets/ud-mark.svg`: marca gráfica de Universal Dynamix.

## Publicación
Podés subir la carpeta completa a un servicio de alojamiento web estático. Mantené juntos el HTML, CSS, JavaScript y la carpeta `assets`.

## Fuentes externas
Los enlaces a NASA, ESA y Smithsonian están incluidos en la sección “Fuentes”. La tipografía web se carga desde Google Fonts; si no hay conexión, se usarán fuentes alternativas.

## Nota educativa
Las fechas futuras se presentan como posibilidades y objetivos de investigación, no como logros garantizados. La información sobre el telescopio Nancy Grace Roman refleja su lanzamiento del 30 de agosto de 2026, según NASA.
